# Ansible Collections 🎭

**Playbooks, not play-by-ear.** Reusable Ansible collections and roles that
turn a freshly provisioned box into a working service, idempotently, so
running them twice is just as boring as running them once. (Boring is the goal.)

SSH-ing into forty hosts by hand is a cry for help. These are the answer.

## Start here

| Repository | What it does |
| --- | --- |
| [`ansible-ai-agents`](https://github.com/jpe-ansible/ansible-ai-agents) | Ansible collection for AI agent hosts. Roles for the robots. |
| [`ansible-nautobot`](https://github.com/jpe-ansible/ansible-nautobot) | Ansible collection for Nautobot: server, sync, pre-flight and drift roles. |

Full architecture and how these fit the bigger picture:
[docs.jacobpevans.com](https://docs.jacobpevans.com).
